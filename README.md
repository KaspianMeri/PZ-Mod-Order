Load order file for **PZ Leam's Collection**.

## Installation

1. Download `sorted_mods_info.ini`.
2. Place it in:

   `%UserProfile%\Zomboid\Lua\`

3. Replace the existing `sorted_mods_info.ini` if necessary.
4. Launch Project Zomboid.
